Instalar como Aplicación (PWA)

PWA Lista con Manifiesto, Icono y Modo Offline

Esta aplicación incluye Web App Manifest, Service Worker y almacenamiento persistente en LocalStorage para funcionar a pantalla completa como una app nativa.

Tu navegador permite instalación directa con un clic:

Opción A: Descargar App Autónoma (.HTML) o abrir en tu navegador

Si estás viendo la app dentro de una vista previa, puedes descargar el archivo único con todo tu progreso incluido para abrirlo en Chrome, Edge o Safari e instalarlo en tu pantalla de inicio:

Opción B: Añadir a la pantalla de inicio desde el navegador
  • Android (Chrome): Toca el menú ⋮ (arriba a la derecha) y selecciona "Instalar aplicación" o "Añadir a pantalla de inicio".
  • iPhone / iPad (Safari): Toca el botón Compartir y elige "Añadir a pantalla de inicio".
  • PC / Mac (Chrome o Edge): Haz clic en el icono de instalación situado a la derecha de la barra de direcciones.

Exportar e Importar Progreso entre Dispositivos

Copia este código para llevar todo tu progreso (películas, capítulos vistos y notas) a otro móvil u ordenador sin servidor:

Conexión de Imágenes: IMDb / TVMaze / Wikipedia / Cómics

Motor Automático Activo (Sin necesidad de claves)

La aplicación ya descarga automáticamente en segundo plano las portadas oficiales:

  • Series, Temporadas y Fotogramas de cada Episodio: Conectado en tiempo real a la API de TVMaze (vinculada por ID de IMDb) para traer el póster de cada temporada, la foto real de cada capítulo y su sinopsis.
  • Películas (UCM, Fox y Sony) y Cómics Canon: Conectado a la API REST de Wikimedia / Wikipedia y OpenLibrary Covers para obtener los pósters de cine y portadas oficiales de los cómics.

IMDb bloquea el acceso directo desde navegadores sin clave, pero a través de OMDb API (servicio gratuito con millones de pósters de IMDb) puedes introducir tu API Key opcional para priorizar los pósters directos de IMDb:
